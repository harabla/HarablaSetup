vJoy / Joystick Gremlin — MPS context pairing

The wheel exposes 12 unique buttons per MPS dial. We use MPS-L's position as the context selector for ENC-L — turn the dial to pick what the left encoder adjusts, then twist the encoder to change the value. ENC-R = Brake Bias stays direct (most-used adjustment). Standard real-F1-wheel pattern. Requires vJoy + Joystick Gremlin to dispatch encoder events to different vJoy buttons based on MPS state.

The stack

  1. Install vJoy driver — creates a virtual joystick (up to 128 buttons, 8 axes). sourceforge.net/projects/vjoystick
  2. Install HidHide — hides the raw Fanatec wheel from games so iRacing only sees the vJoy device. github.com/nefarius/HidHide
  3. Install Joystick Gremlin — routes physical → vJoy with mode/state logic. whitemagic.github.io/JoystickGremlin
  4. In Gremlin, create 12 modes: MPS-L-pos1 … MPS-L-pos12. For each MPS-L position button, add an action: "Switch to mode MPS-L-posN" (latched, not held).
  5. In each mode, route ENC-L CW / CCW to a different vJoy button (e.g. mode 1 → vJoy 71/72 = Fuel Mix +/−, mode 2 → vJoy 73/74 = TC2 +/−, …).
  6. In iRacing Controls, bind Fuel Mix increment to vJoy 71, Fuel Mix decrement to vJoy 72, and so on for every encoder context.

Why this pattern

  • Physical state visible — the MPS dial clicks into each slot, so you always know what ENC-L is currently tuning. No on-screen indicator needed.
  • F1 muscle memory — same pattern as real-world Mercedes / Ferrari / RB wheels.
  • iRacing-legal — vJoy/Gremlin/HidHide are openly discussed on iRacing's forums. Anti-cheat does not inspect input drivers.
  • Reversible — disable HidHide and the wheel works exactly as before.
  • BB stays direct — ENC-R is unchanged, no context dance for the most-used adjustment.

What Gremlin enables beyond MPS context

  • Macros — one press fires a sequence of vJoy buttons + keystrokes with timing (e.g. long-press B1 → "Tow + Reset").
  • Synthetic axes — turn an encoder's CW/CCW button presses into a sweeping axis (useful for iRacing inputs that only accept axis, not buttons).
  • Conditional logic — fire different actions based on which MPS mode is active, or chord (A+B = X).
  • Multiple context dials — same trick with MPS-R if you ever want it; today we keep MPS-R direct as TC Level.

Per-app audio (Discord / Spotify / Game) — VR-friendly

MPS-L positions 10–12 control OS-level per-app volume. iRacing can't bind these — Gremlin fires a small command-line script per encoder detent. Useful in VR when you can't reach the keyboard or see the Stream Deck.

Easiest tool: NirSoft SoundVolumeView

Free, single .exe, handles multi-process apps like Discord cleanly. nirsoft.net/utils/sound_volume_view.html

SoundVolumeView.exe /ChangeVolume "Discord"   +5
SoundVolumeView.exe /ChangeVolume "Discord"   -5
SoundVolumeView.exe /ChangeVolume "Spotify"   +5
SoundVolumeView.exe /ChangeVolume "Spotify"   -5
SoundVolumeView.exe /ChangeVolume "iRacingSim64DX11" +5
SoundVolumeView.exe /ChangeVolume "iRacingSim64DX11" -5

In Gremlin: in mode MPS-L-pos10, bind ENC-L CW → Run program action with the +5 command, ENC-L CCW → −5 command. Same pattern for pos 11 / 12.

Alternative: nircmd

nircmd.exe setappvolume discord.exe +0.05
nircmd.exe setappvolume spotify.exe -0.05
nircmd.exe setappvolume iRacingSim64DX11.exe +0.05

Note: app name must match the .exe (Discord) or window title (varies). SoundVolumeView lets you list current sessions with /SaveFileEncoding 3 /Sstop "" sessions.txt if names don't work.

Caveats

  • Exact HID button-numbers per control depend on firmware revision — verify in Windows joy.cpl with Gremlin's input viewer before authoring mappings.
  • MPS positions fire only on change, not continuously — Gremlin's "Switch to mode" action handles this fine. If a position is missed, the encoder routes to whatever mode was last selected (so it can't break, just be in the wrong context).
  • Some iRacing adjustables (Diff axes, Brake Migration, TC2) are car-specific — bindings exist game-wide but only do something when the active car exposes them.
  • Side joysticks may be 4-way or 8-way depending on your unit. Check joy.cpl — if diagonals fire, treat them as separate inputs in Gremlin.

PC Setup — building this rig from the spec

First-time-on-PC walkthrough. Doubles as the rebuild guide if you ever move to another machine. Follow top-to-bottom; each step is independent and resumable. Designed on Mac, executed on Windows.

Hardware check, base utility tools, display toggle scripts, Stream Deck profiles. Required for everything; doesn't assume a wheel.

🩺 Health check & rig config (planned tooling)

Design notes for a small standalone PowerShell app that verifies installs, checks expected configs, and stores per-PC paths so other scripts (monitoring, display toggles, audio scripts) don't need hard-coded paths.

What the app does

  • setup.ps1 — first-run installer. Uses winget + GitHub releases API + portable downloads to install ~70% of the stack unattended. Prompts user for the ~30% that's vendor-bound (FanaLab, iRacing, Stream Deck app, Trading Paints, Virtual Desktop). Generates all .bat scripts (display + audio) automatically.
  • health-check.ps1 — runnable any time. Probes every tool / config / file. Outputs health.html with ✅ / ⚠️ / ❌ per item, "Fix" buttons for repairable issues (re-copy controls.cfg, re-apply Gremlin profile, etc.).
  • rig-config.json — single source of truth for per-PC paths. Read by all monitoring + setup scripts so we never hard-code C:\Program Files (x86)\iRacing\.

Adding PUBG monitoring becomes trivial — just populate the games.PUBG entry and re-use the same script.

🏎 iRacing-specific setup (only if you race)

Wheel + sim software. Skip entirely if this PC isn't for racing.

  1. Fanatec hardware check + HID inventory

    • Fanatec wheelbase powered, wheel attached, USB to PC. Open Windows joy.cpl → confirm "Fanatec ClubSport SW Formula V2.5" (or wheelbase name) shows up. Wiggle every control and watch buttons fire.
    • Note the raw HID button numbers per control (B1=#?, MPS-L pos 1=#?, ENC-L CW=#?). You'll need these when building the Gremlin profile.

  2. Install Fanatec stack

    • Install Fanatec driver for your wheelbase. fanatec.com/support/downloads
    • Install FanaLab on top.
    • Run wheelbase firmware update if prompted. Don't skip — older firmware has different HID button numbering.
    • In FanaLab, create three profiles: GT3 / GTE, LMP / GTP, Formula. Settings per profile per the iRacing tab's FanaLab table.
    • Test FFB with any car in iRacing test session before continuing.

  3. Install vJoy + HidHide + Joystick Gremlin

    • Install vJoy driver. sourceforge.net/projects/vjoystick
      Open Configure vJoy →
      • Device 1: 128 buttons, 0 axes, 0 POVs, Force Feedback OFF. Apply. (Used by Joystick Gremlin for our wheel button mapping.)
      • Device 2: 0 buttons, 1 axis (X), 0 POVs, Force Feedback ON (tick all FFB effect types). Apply. (Used by iRFFB 2022 — iRacing outputs FFB to this device, iRFFB intercepts and post-processes.)
    • Install HidHide. github.com/nefarius/HidHide
      Open HidHide Configuration:
      • Applications tab: add JoystickGremlin.exe (so Gremlin sees the raw wheel) AND add iRacingSim64DX11.exe + iRacingUI.exe (so iRacing sees only vJoy).
      • Devices tab: tick "Hide" next to your Fanatec wheelbase entry. Tick "Enable device hiding" at top.
    • Install Joystick Gremlin. whitemagic.github.io/JoystickGremlin
    • Confirm in joy.cpl: you should now see vJoy Device AND no longer see Fanatec (because HidHide hid it from joy.cpl too).

  4. Build the Joystick Gremlin profile

    This is the brain of the whole rig. Save the profile as fanatec-iracing.xml and back it up.

    1. Add inputs: Gremlin → File → New profile. Add Fanatec wheel as input device, vJoy Device 1 as output.
    2. 1:1 base mapping: in Default mode, route every physical Fanatec button to a vJoy button (e.g. raw #1 → vJoy 1, raw #2 → vJoy 2, ...). Use Gremlin's "Map to vJoy button" action.
    3. Create 12 modes for the MPS-L context: name them MPS-L-pos1 … MPS-L-pos12. (Profile menu → Edit modes → Add.)
    4. Wire mode switching: each MPS-L position button gets a "Switch mode" action targeting its matching mode (latched, NOT held). MPS-L pos 1 button → switch to MPS-L-pos1, etc.
    5. Per-mode ENC-L routing: in each MPS-L-posN mode, override ENC-L CW and CCW to fire a unique vJoy button:

  5. Install iRFFB 2022 (force-feedback post-processor)

    • Download iRFFB 2022 from github.com/blarghedy/iRFFB2022/releases → install.
    • In iRFFB: Wheel/joystick → select your real Fanatec wheel. vJoy device → Device 2 (configured in step 4 with FFB ON).
    • Set damping / spring / friction → 0% (iRFFB does these in software).
    • Set strength per-car (per iRFFB community presets — GT3 around 25–35 Nm equivalent on a CSL DD).
    • In iRacing → Options → Drive → Force Feedback: tick "Use linear mode", set strength per car, set device = vJoy Device 2 (so iRacing's FFB output goes to iRFFB, not directly to the wheel).
    • iRFFB must be running BEFORE you launch iRacing — the monitor script (next step) doesn't currently start it. Add it manually to startup or include it in your pre-flight routine.
    • Test in any practice session — feel for the curb / road texture iRFFB adds. If it feels worse than stock, iRFFB strength is probably too high.

  6. OS-level audio scripts (MPS-L pos 10–12)

    Install SoundVolumeView first: nirsoft.net → drop SoundVolumeView.exe into C:\Tools\SoundVolumeView\. Then create six tiny .bat files Gremlin will shell out to:

    REM discord-up.bat
"C:\Tools\SoundVolumeView\SoundVolumeView.exe" /ChangeVolume "Discord" +5

REM discord-down.bat
"C:\Tools\SoundVolumeView\SoundVolumeView.exe" /ChangeVolume "Discord" -5

REM spotify-up.bat   /  spotify-down.bat   (same pattern with "Spotify")
REM iracing-up.bat   /  iracing-down.bat   (same with "iRacingSim64DX11")

    In Gremlin, in mode MPS-L-pos10: ENC-L CW → "Run program" action → discord-up.bat. ENC-L CCW → discord-down.bat. Repeat for pos 11 (Spotify) and pos 12 (iRacing).

  8. Bind external apps (Discord, Crew Chief)

    These don't go through iRacing — Discord and CC have their own input bindings.

    Discord — TOG-L = push-to-talk

    1. Discord → Settings → Voice & Video → Input Mode = Push to Talk.
    2. Click "Edit Keybind" under "Shortcut" → press TOG-L on the wheel. Discord should register it as "vJoy Button 91" (or your chosen vJoy button #).
    3. If Discord doesn't accept vJoy buttons (some builds don't): change Gremlin's TOG-L action to keyboard F13, then bind F13 in Discord.
    4. Set "Push to Talk Release Delay" to 100–200 ms so the tail of your sentence isn't cut off.

    Crew Chief — TOG-R = push-to-listen

    The launcher script

    Save as C:\Tools\Monitoring\monitor-iracing.ps1. Adjust paths as needed.

    # monitor-iracing.ps1 — wraps an iRacing session with full telemetry capture
# Run via:  powershell -ExecutionPolicy Bypass -File C:\Tools\Monitoring\monitor-iracing.ps1

$ErrorActionPreference = 'Continue'
$timestamp = Get-Date -Format 'yyyy-MM-dd_HHmm'
$logDir    = "C:\Logs\iracing\$timestamp"
$tools     = "C:\Tools"
New-Item -ItemType Directory -Force -Path $logDir | Out-Null

Write-Host "[monitor] session: $timestamp" -ForegroundColor Cyan
Write-Host "[monitor] log dir: $logDir"

# 1. SNAPSHOT graphics + VR settings
$iRacingDocs = "$env:USERPROFILE\Documents\iRacing"
foreach ($f in @('app.ini','rendererDX11.ini','dxconfig.ini')) {
  if (Test-Path "$iRacingDocs\$f") {
    Copy-Item "$iRacingDocs\$f" "$logDir\$f.snapshot"
  }
}
if (Test-Path "$env:APPDATA\OpenXR-Toolkit\settings.cfg") {
  Copy-Item "$env:APPDATA\OpenXR-Toolkit\settings.cfg" "$logDir\openxr-toolkit.cfg.snapshot"
}
# Snapshot active iRacing setups dir (last-modified .sto files)
$setupsDir = "$iRacingDocs\setups"
if (Test-Path $setupsDir) {
  Get-ChildItem $setupsDir -Recurse -Filter "*.sto" |
    Sort-Object LastWriteTime -Descending |
    Select-Object -First 10 |
    ForEach-Object { Copy-Item $_.FullName "$logDir\setup-$($_.Name)" }
}

# 2. START HWiNFO64 with CSV logging (background)
Start-Process "C:\Program Files\HWiNFO64\HWiNFO64.exe" `
  -ArgumentList "/log=$logDir\hwinfo.csv" -WindowStyle Minimized

# 3. START PresentMon (auto-attaches to iRacingSim64DX11.exe when it starts)
$presentMonExe = Get-ChildItem "$tools\PresentMon\PresentMon-*-x64.exe" | Select-Object -First 1
Start-Process $presentMonExe.FullName `
  -ArgumentList "-process_name iRacingSim64DX11.exe -output_file `"$logDir\presentmon.csv`" -terminate_on_proc_exit -no_top" `
  -WindowStyle Hidden

# 4. BACKGROUND POLLER — top processes every 5s
$pollerJob = Start-Job -ScriptBlock {
  param($logFile)
  "timestamp,process,cpu_percent,ram_bytes" | Out-File $logFile
  while ($true) {
    $now = Get-Date -Format 'HH:mm:ss'
    Get-Process | Where-Object { $_.WorkingSet64 -gt 50MB } |
      Sort-Object WorkingSet64 -Descending | Select-Object -First 15 |
      ForEach-Object {
        try {
          $cpuSample = Get-Counter "\Process($($_.ProcessName))\% Processor Time" -ErrorAction Stop
          $cpu = [math]::Round($cpuSample.CounterSamples[0].CookedValue, 2)
        } catch { $cpu = 0 }
        "$now,$($_.ProcessName),$cpu,$($_.WorkingSet64)" | Out-File $logFile -Append
      }
    Start-Sleep -Seconds 5
  }
} -ArgumentList "$logDir\processes.csv"

# 5. LAUNCH iRacing UI
$iRacingUI = Start-Process "C:\Program Files (x86)\iRacing\iRacingUI.exe" -PassThru
Write-Host "[monitor] iRacing launched (PID $($iRacingUI.Id))" -ForegroundColor Green

# 6. WAIT for entire iRacing process tree to exit
Start-Sleep -Seconds 30  # let iRacing actually start
while ((Get-Process iRacingSim64DX11 -ErrorAction SilentlyContinue) -or `
       (Get-Process iRacingUI -ErrorAction SilentlyContinue)) {
  Start-Sleep -Seconds 5
}
Write-Host "[monitor] iRacing exited; cleaning up" -ForegroundColor Yellow

# 7. CLEANUP
Stop-Job $pollerJob; Remove-Job $pollerJob
Stop-Process -Name HWiNFO64 -Force -ErrorAction SilentlyContinue
Stop-Process -Name PresentMon* -Force -ErrorAction SilentlyContinue

# 8. GENERATE REPORT
& "$tools\Monitoring\generate-report.ps1" -LogDir $logDir
Start-Process "$logDir\report.html"
Write-Host "[monitor] report opened: $logDir\report.html" -ForegroundColor Cyan

    The report generator

    Save as C:\Tools\Monitoring\generate-report.ps1. Produces a single self-contained HTML file with Chart.js (CDN) charts.

    param([Parameter(Mandatory)][string]$LogDir)

# Parse processes.csv → top consumers
$procs = Import-Csv "$LogDir\processes.csv"
$topByCpu = $procs | Group-Object process | ForEach-Object {
  [PSCustomObject]@{
    Name    = $_.Name
    AvgCpu  = ($_.Group.cpu_percent | Measure-Object -Average).Average
    PeakCpu = ($_.Group.cpu_percent | Measure-Object -Maximum).Maximum
    AvgRam  = ($_.Group.ram_bytes   | Measure-Object -Average).Average / 1MB
  }
} | Sort-Object PeakCpu -Descending | Select-Object -First 15

# Parse PresentMon for FPS / frametime
$frames = @()
if (Test-Path "$LogDir\presentmon.csv") {
  $frames = Import-Csv "$LogDir\presentmon.csv"
  $msPerFrame = $frames.MsBetweenPresents | ForEach-Object { [double]$_ }
  $avgFps    = if ($msPerFrame.Count -gt 0) { [math]::Round(1000 / ($msPerFrame | Measure-Object -Average).Average, 1) } else { 0 }
  $sortedMs  = $msPerFrame | Sort-Object
  $p99       = if ($sortedMs.Count -gt 0) { $sortedMs[[int]($sortedMs.Count * 0.99)] } else { 0 }
  $stutters  = ($msPerFrame | Where-Object { $_ -gt 33 }).Count   # frames > 33ms = below 30 FPS
}

# Parse iRacing app.ini for graphics settings
$iniSettings = @{}
if (Test-Path "$LogDir\app.ini.snapshot") {
  Get-Content "$LogDir\app.ini.snapshot" | ForEach-Object {
    if ($_ -match '^\s*([^=;\s]+)\s*=\s*(.+)$') {
      $iniSettings[$matches[1]] = $matches[2].Trim()
    }
  }
}
$keysOfInterest = @('Resolution','MultiSamples','MaxQuality','MirrorHigh','ShadowMaps','Particles','EventDistance')
$gfxSummary = $keysOfInterest | ForEach-Object {
  if ($iniSettings.ContainsKey($_)) {
    [PSCustomObject]@{ Setting = $_; Value = $iniSettings[$_] }
  }
}

# Build HTML
$html = @"
<!doctype html>
<html><head><meta charset='utf-8'>
<title>iRacing session report — $(Split-Path $LogDir -Leaf)</title>
<script src='https://cdn.jsdelivr.net/npm/chart.js'></script>
<style>
body{font-family:system-ui;background:#0a0d12;color:#e0e0e0;padding:24px;max-width:1200px;margin:auto}
h1,h2{color:#5a8;border-bottom:1px solid #333;padding-bottom:6px}
table{border-collapse:collapse;width:100%;margin:12px 0}
th,td{text-align:left;padding:6px 12px;border-bottom:1px solid #222}
th{color:#888;font-size:12px;text-transform:uppercase}
.metric{display:inline-block;background:#1a2030;padding:12px 18px;border-radius:8px;margin:6px}
.metric .v{font-size:24px;font-weight:700;color:#5a8}
.metric .l{font-size:11px;color:#888;text-transform:uppercase}
canvas{background:#1a1d22;border-radius:8px;padding:12px;margin:12px 0}
</style></head><body>
<h1>iRacing session — $(Split-Path $LogDir -Leaf)</h1>

<div>
  <div class='metric'><div class='v'>$avgFps</div><div class='l'>Avg FPS</div></div>
  <div class='metric'><div class='v'>$([math]::Round($p99,1)) ms</div><div class='l'>P99 frametime</div></div>
  <div class='metric'><div class='v'>$stutters</div><div class='l'>Stutters (>33ms)</div></div>
</div>

<h2>Top processes by peak CPU</h2>
<table><tr><th>Process</th><th>Peak CPU %</th><th>Avg CPU %</th><th>Avg RAM (MB)</th></tr>
$($topByCpu | ForEach-Object { "<tr><td>$($_.Name)</td><td>$([math]::Round($_.PeakCpu,1))</td><td>$([math]::Round($_.AvgCpu,1))</td><td>$([math]::Round($_.AvgRam,0))</td></tr>" })
</table>

<h2>Graphics settings (from app.ini snapshot)</h2>
<table><tr><th>Setting</th><th>Value</th></tr>
$($gfxSummary | ForEach-Object { "<tr><td>$($_.Setting)</td><td>$($_.Value)</td></tr>" })
</table>

<h2>Frametime over session</h2>
<canvas id='frametime' height='80'></canvas>
<script>
const ms = $((($msPerFrame | Select-Object -First 5000) -join ',') -replace '^,','');
new Chart(document.getElementById('frametime'), {
  type: 'line',
  data: { labels: ms.map((_,i)=>i), datasets: [{ label:'ms', data: ms, borderColor:'#5a8', borderWidth:1, pointRadius:0 }] },
  options: { animation:false, scales:{ y:{ suggestedMin:0, suggestedMax:50 } } }
});
</script>

<h2>Files in this session</h2>
<ul>
$($snapshots = Get-ChildItem $LogDir | ForEach-Object { "<li><code>$($_.Name)</code> ($([math]::Round($_.Length/1KB,1)) KB)</li>" })
$snapshots
</ul>

</body></html>
"@

$html | Out-File "$LogDir\report.html" -Encoding utf8
Write-Host "[report] generated: $LogDir\report.html" -ForegroundColor Cyan
